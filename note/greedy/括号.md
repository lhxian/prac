# 贪心算法解决括号类题目

在一些题目中，括号的闭合性质通常可以使用贪心的思路来解决。
假设一个括号序列中只有一种括号类型，例如只有圆括号()，那么对于一个合法的括号序列，有如下的性质：
在任意位置插入一对括号之后，原来的合法括号序列仍然是合法的。
[题目链接](https://codeforces.com/problemset/problem/2196/D)
题目中要求的合法括号可以当作一个合法()序列和一个合法[]序列的混合，可以使用贪心的方式，首先，对()序列和[]序列，分别先排除那些不需要进行改变的括号，利用栈计数即可。
排除那些不必要括号之后，接下来考虑那些可以通过改变一个括号即可产生一对合法括号的位置，有之前的性质可知，添加一对括号，不会改变原来括号序列的合法性。将剩下的括号分为两部分，一部分之包含左括号'(','['，这部分可以只改变一个就会产生一对括号，同理对于右括号也这样做。
最后剩下那些必须通过同时改变两个括号才能产生合法括号的序列，例如"](",")["。
由于序列是偶数的，所以排除不必须修改的括号之后，得到的左括号和右括号的数量是同奇偶的，如果左括号数量是偶数，那么所有的括号对都可以通过改变一个括号即可产生；如果是奇数，那么只有一个括号对可能需要通过同时改变两个括号来产生。
如果是奇数，下面的情况不需要同时改变两个括号即可产生最后的那个括号对。
```
[({[[[
    |
    ))))]]
```
我们可以扫描一遍剩下的括号，分别求出左括号和右括号的覆盖范围，如果存在一个左括号a和右括号b,它们的位置满足：
$ pos(a) < pos(b) $
那么将a,b视为一对括号，只需要修改一个即可，所以我们只需要记录最左的左括号和最右的右括号，但剩下的左右括号数量为奇数的时候，尝试看一下这两个位置的括号能否满足位置关系，如果满足只需要改变一个括号即可。
