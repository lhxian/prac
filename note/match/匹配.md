# k分图的匹配
一个图是k分图，例如3分图，匹配规则为(a,b,c)三元组中，a,b,c分别来自3分图中的不同部分，并且(a,b),(b,c)是图中的边。
可以使用网络流来进行建模，对于3分图，有一个主要注意的地方，就是第二层需要进行扩展，也就是原先第二层的图的节点需要分裂成为两个，A1,A2，在两者之间连一条容量为1的边，这是因为存在如下的情况：
```
源点     s
第一层 a     b
        \   /
第二层    c
        /  \
第三层  d   e
        |   |
汇点    t
```
上面的情况中，最大流中，a,b的流量都经过了第二层的c点，并且后面第三层的节点也允许这样的流进入汇点，不符合三元组的形式，所以可以将第二层的节点进行分裂，限制经过第二层的节点流量为1。
