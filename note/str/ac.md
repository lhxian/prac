# 一些比较巧妙的题目解法
[题目](https://www.luogu.com.cn/problem/P14363)
[代码](../code/P14363_luogu.cc)
题目大意：
给出多对长度相同的字串(a,b)，表示字符串a可以变为b,然后有多组询问：
每次询问两个字符串s,t(s!=t)，求存在多少个变换，是的可以将s变为t.
思路：转换为AC自动机上的多个字串匹配问题，
一个变换可以表示为**S=A?B?C**,其中A为a和b的最长公共字串，B为a和b的最长公共后缀，?选择一个不在当前字符集的字符作为特殊标记。
同样也对s和t进行上面的表示T。
将多个变换构建AC自动机，一个变换合法当且仅当它是T的字串，这是因为存在特殊字符?，所以如果变换S是T的字串，那么两个特殊字符?也一定匹配了T,这说明已经能够实现s到t的变换了（s->t等价与T中的两个?都被匹配）
题目中的一个重要信息是一个变换最多只能使用一次，这是的将问题转换为模式匹配成为可能。
