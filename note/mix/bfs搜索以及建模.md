# 可以使用bfs搜索建模的问题

[题目链接](https://ac.nowcoder.com/acm/contest/142560/D)

首先可以通过遍历每个顶点，以每个顶点为源点进行bfs,求出任意两点之间的距离，时间复杂度是平方级别。
把两个人的位置视为一个状态(a,b)，a,b分别表示两人所在的顶点，满足$ a !=b $，同时$dis(a,b) <= k$，考虑使用bfs搜索来寻找状态(s,t)到状态(t,s)而最短距离，对于一个状态(a,b)，它可以转移的状态为：
```
(a,b) -> (a,v), a,v有边并且满足dis(a,v) <=k;
(a,b) -> (v,b), b,v有边并且满足dis(b,v) <=k;
```
题目中的数据，一个顶点的度数大概为$3000/600 =5$，所以如果不出现类似星形的图结构，一个状态的邻居数量可以看成常数级别。
